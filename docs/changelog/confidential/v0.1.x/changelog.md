# Confidential changelog

Release notes for the optional `github.com/Peersyst/xrpl-go/confidential` module. This module contains confidential MPT builders and cryptographic helpers, with its own versions and `confidential/vX.Y.Z` release tags.

- [v0.1.0](./999_v0_1_0.md): the first independent release, requiring core `v0.3.1` or later.
- [Installation and migration](/docs/confidential/installation).
- [Core changelog](/changelog/v0.3.x/changelog) for transaction models, codecs, clients, and wallet signing.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this module follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
